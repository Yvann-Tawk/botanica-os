Variables & data types

    2.

Stage 1 of 5 · Discover

Every specimen needs a label.

A variable is a name you tie to a value, like a tag looped around a jar in the seed bank. Write the name, an equals sign, then the value. From then on, Python can find that value again whenever you use the name.

By the end of this lesson you can · create variables with = · tell int, float, str and bool apart · inspect any value with type()
{{tk.t}}

The four types you will meet first

int

Whole numbers

42 · -7 · 0

float

Numbers with a decimal point

18.5 · 3.0 · -0.25

str

Text, always in quotes

"Moonfern" · '42'

bool

Truth: one of two values

True · False

Field tip. Not sure what you are holding? type() tells you. The code on the right already prints type(height_cm). Press Run and read the console.

Stage 2 of 5 · Experiment

Change the jar, watch the label change.

The code on the right is live. Run it, then poke at it. Nothing you type here can damage the vessel, and every error is a clue.

  1. Run it as it is. Press Run or ⌘ Enter.
  2. Change 42 to 42.0 and add print(type(age_days)). The label switches from int to float.
  3. Put the number in quotes: age_days = "42". Now it is a str, text that only looks like a number.
  4. Try print(specimen + age_days). Read the last line of the error slowly.
Python decides the type from the value, never from the name. Names are for you, so make them describe what they hold.

Stage 3 of 5 · Practice

Log the vessel's home star.

The navigation log needs three facts about Hortensia Prime. Each one is a different type. The last line is already written: it fills itself in once your variables exist.

  1. star: the name Hortensia Prime, as a str
  2. distance_ly: 4.2 light-years, as a float
  3. moons: 3 moons, as an int
